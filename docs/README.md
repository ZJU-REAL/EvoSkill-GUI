# EvoSkill-GUI project page

Static project page for **Reflect, Revise, Reuse: Training-Free Skill Evolution for GUI Agents**.

## Preview

From the repository root:

```bash
python -m http.server 8000 -d docs
```

Then open `http://localhost:8000`.

## Publish

In the GitHub repository settings, enable GitHub Pages with **Deploy from a branch**, select the default branch, and use the `/docs` folder.

## Release checklist

Before the public release, replace the disabled **Paper / Coming soon** control with the final arXiv link and add the official BibTeX entry.
